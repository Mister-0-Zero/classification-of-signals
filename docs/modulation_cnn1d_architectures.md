# Сравнение архитектур 1D CNN для AM/FM/Noise

Проверены четыре изменения: сохранение частотных отсчётов, позднее
сжатие с гибридным выходом, расширение полосы свёрток с дилатацией
и большее число частотных зон перед полносвязной частью.

## Архитектуры

На входе один спектр из 501 точки с шагом 500 Гц. В обозначении
`Conv(C, K)` число C задаёт каналы, K — размер ядра в отсчётах.
После каждой свёртки применяется ReLU. Если шаг не указан, он равен 1.

| Вариант | Свёрточная часть и частотная ось | Усреднение и выход | Параметры |
|---|---|---|---:|
| Базовая CNN, 5 зон | Conv(16, 9), шаг 2: 251 → MaxPool(2): 125 → Conv(32, 5): 125 | Среднее по 5 зонам → Linear(160, 3) | 3 235 |
| Базовая CNN, всё окно | Та же свёрточная часть | Среднее по окну → Linear(32, 3) | 2 851 |
| Полное разрешение | Conv(16, 9): 501 → Conv(32, 5): 501 | Среднее по 5 зонам → Linear(160, 3) | 3 235 |
| Позднее сжатие, гибрид | Conv(16, 9): 501 → Conv(24, 7): 501 → AvgPool(2): 250 → Conv(32, 7): 250 | Средние по 5 зонам + глобальное среднее и максимум → 224 → 32 → 3 | 15 579 |
| Гибрид с дилатацией | Как поздний гибрид, дилатация по слоям 1 / 3 / 9 | Та же полносвязная часть 224 → 32 → 3 | 15 579 |
| Позднее сжатие, 25 зон | Как поздний гибрид, дилатация 1 / 1 / 1 | Средние по 25 зонам → 800 → 64 → 3 | 59 739 |

Дилатация увеличивает расстояние между отсчётами, которые использует
один фильтр. Здесь она расширяет контекст глубокой свёртки без
дополнительного уменьшения числа точек. Полносвязные скрытые слои,
где они есть, используют ReLU.

На основной выборке лучшая CNN — вариант с 25 зонами. Он отбросил
как шум **75 из 3 750** реальных сигналов, против 110 у MLP и 100
у итогового GB. Его Macro F1 немного ниже MLP, но выше результата
GB на тех же одиночных спектрах (0,864).

Глобальная базовая CNN распознала чуть больше смещённых FM, но на
основной выборке она гораздо чаще назначала FM спектрам AM и шума.
Гибрид с дилатацией сохранил близкую полноту на смещённых FM при более
высоком Macro F1 на основной выборке и меньшем числе ложных меток FM.
Среди новых архитектур он лучше всего справился со смещением.

## Протокол

Те же 97 записей, 4 850 одиночных спектров и девять внешних фолдов
с разделением по группам. Отдельно проверены те же 750 смещённых FM.
Станции из теста полностью исключены из обучения. Для станции, которой
нет в основных записях, использована модель на всех основных группах.
Сдвиги при обучении, усреднение нескольких трасс и dropout не использовались.
Эпоха выбиралась на внутренних группах с учётом пропусков реального сигнала.

Вычисления измерялись после прогрева на одном потоке Ryzen 5 7500F:
подготовка входа плюс один прогноз, без времени развёртки анализатора.
На смещённой выборке есть только FM. Ошибочные прогнозы FM по AM и
шуму оценены отдельно на основной выборке.
