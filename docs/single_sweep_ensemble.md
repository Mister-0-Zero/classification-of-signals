# Совместный прогноз MLP и Gradient Boosting на одном спектре

На 5 600 одинаковых отложенных одиночных развёртках сопоставлены
вероятностные оценки [компактной MLP](fast_mlp.md) и
[GB с уточнением центра](gb_confidence.md). Прогнозы совпадают по
записи, номеру развёртки, классу, группе и фолду.

Сравнивались взвешенное среднее трёх оценок, разделение задачи
обнаружения и выбора модуляции, а также правила, по которым
наличие сигнала должна подтвердить любая либо каждая модель.
Порог сигнала применяется к сумме оценок AM и FM.

| Правило | Macro F1 | Сигнал → шум | Шум → сигнал | Смещённые FM → FM |
|---|---:|---:|---:|---:|
| MLP, порог 0,30 | 0,8922 | 170 | 111 | 646 / 750 |
| GB, порог 0,30 | 0,8064 | 68 | 341 | 642 / 750 |
| 75% MLP + 25% GB, порог 0,40 | 0,9020 | 145 | 103 | 662 / 750 |
| 75% MLP + 25% GB, порог 0,30 | 0,8987 | 104 | 151 | 684 / 750 |
| Достаточно одной модели, порог каждой 0,30 | 0,8452 | 38 | 376 | 718 / 750 |

Медиана максимальной оценки составила 0,991 у MLP и 0,976 у GB
на одиночных трассах. Значения не калибровались. Веса и пороги
сравнивались на том же наборе, поэтому решение о настройках
нужно подтвердить на новых группах.

Обе модели используют одну развёртку. По отдельным замерам p50
составляет 0,042 мс у MLP и 1,068 мс у GB. Ориентир для
последовательного запуска — около 1,1 мс вычислений на спектр.
Это сумма медиан отдельных замеров. Совместный цикл и параллельный
запуск отдельно не измерялись.

## Воспроизведение

```powershell
python scripts/evaluate_single_sweep_ensemble.py --gb .local/gb1/predictions.csv --mlp .local/fast_mlp/compact_shift_predictions.csv --output .local/single_sweep_ensemble
```
