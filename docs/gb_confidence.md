# Уверенность Gradient Boosting и каскад с Deep Sets

Используется GB с [уточнением центра по измеренному спектру](neural_shift_augmentation.md).
Оценки получены для отложенных групп. На общем тесте из 4 592 окон
отдельно рассмотрены случаи, когда GB пропускает сигнал, принимает
шум за сигнал или путает AM с FM. Уверенность — максимальная оценка
из трёх выходов `predict_proba`.

| Ответ GB на семи спектрах | Окон | Медиана оценки | Оценка ≥ 0,90 | Оценка ≥ 0,99 |
|---|---:|---:|---:|---:|
| Верный | 4 411 | 1,000 | 4 362 | 4 293 |
| Шум принят за сигнал | 74 | 0,970 | 50 | 31 |
| Сигнал принят за шум | 20 | 0,982 | 13 | 9 |
| Перепутаны AM и FM | 87 | 1,000 | 67 | 54 |

Из 100 ответов с оценкой ниже 0,90 ошибочны 59. Среди 4 387 ответов
с оценкой выше 0,99 ошибочны 94. ROC AUC детектора ошибок по
`1 − max(p)` составил 0,849. Низкая оценка выделяет сложные примеры,
но значительная часть ошибок получает высокую оценку. Все верхние
значения округлены. Они не интерпретируются как калиброванные вероятности.

## Два правила принятия решения

Для порога наличия сигнала используется сумма оценок AM и FM, затем
при обнаружении сигнала выбирается наиболее вероятная из модуляций.
Для каскада сравниваем максимальную оценку GB с отдельным порогом.
При оценке ниже порога используем класс уже проверенной Deep Sets
со случайными сдвигами FM. Соединение прогнозов проверено по записи,
номеру развёртки, классу, группе и внешнему фолду.

| Правило, семь спектров | Macro F1 | Смещённые FM → FM | Сигнал → шум | Шум → сигнал | Вызовов Deep Sets |
|---|---:|---:|---:|---:|---:|
| GB по максимуму | 0,9577 | 610 / 615 | 20 | 74 | 0 |
| AM + FM ≥ 0,30 | 0,9545 | 610 / 615 | 17 | 86 | 0 |
| AM + FM ≥ 0,50 | 0,9577 | 610 / 615 | 20 | 74 | 0 |
| AM + FM ≥ 0,95 | 0,9641 | 610 / 615 | 33 | 41 | 0 |
| Deep Sets при max(p) < 0,80 | 0,9660 | 611 / 615 | 14 | 56 | 75 (1,6%) |
| Deep Sets при max(p) < 0,90 | 0,9687 | 611 / 615 | 13 | 50 | 100 (2,2%) |
| Deep Sets при max(p) < 0,99 | 0,9764 | 612 / 615 | 10 | 31 | 205 (4,5%) |

Каскад с порогом 0,90 исправил 45 ответов и испортил 2.
Пороги сравнивались на одной и той же выборке, поэтому для выбора
порога системы требуется отдельный тест на новых группах.

## Решение по одной развёртке

Переобученный на одиночных спектрах GB с уточнением центра получил
Macro F1 0,8171 на 5 600 спектрах. Среди 750 смещённых спектров
он правильно распознал 628. При прямом сравнении на тех же
4 592 конечных развёртках Macro F1 составил 0,8154 для одного
спектра и 0,9577 для семи. Пропусков было 81 и 20 соответственно,
ложных сигналов — 230 и 74.

На совпадающих концах проверен вариант каскада, в котором первым
решает GB по одному спектру. При пороге 0,80 он вызвал Deep Sets для
863 из 4 592 окон (18,8%) и дал 0,8860 Macro F1, 95 пропусков
и 113 ложных сигналов. Здесь Deep Sets использует шесть предыдущих
развёрток. Сценарий запуска с первой развёртки и последующей съёмки
ещё шести требует отдельного прогона в хронологическом порядке.

| Вход GB | p50 / p95 обработки, мс |
|---|---:|
| Один спектр | 1,07 / 1,56 |
| Семь спектров | 1,11 / 1,60 |

582 замера на вариант, один поток CPU. Учтены усреднение, уточнение
центра, признаки и `predict_proba`. Ожидание развёрток на приборе
не измерялось. При последовательной съёмке вариант с семью спектрами
ждёт ещё шесть межкадровых интервалов по сравнению с первым замером.

## Воспроизведение

```powershell
python scripts/evaluate_gb_recentering.py --project . --output .local/gb7 --window 7 --workers 5
python scripts/evaluate_gb_recentering.py --project . --output .local/gb1 --window 1 --workers 5
python scripts/evaluate_neural_shift_augmentation.py --project . --model deep_sets --output .local/deep_sets --training-threads 2
python scripts/evaluate_gb_confidence.py --predictions .local/gb7/predictions.csv --secondary .local/deep_sets --output .local/audit7
python scripts/evaluate_gb_confidence.py --predictions .local/gb1/predictions.csv --secondary .local/deep_sets --min-end-sweep 9 --output .local/audit1
```
