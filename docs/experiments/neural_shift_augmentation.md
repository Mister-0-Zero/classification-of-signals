# Случайные частотные сдвиги для MLP, 1D CNN и Deep Sets

## Данные и обучение

Сравнение ведётся на 4 592 реальных окнах из семи развёрток, включая
615 смещённых окон FM из 15 записей. Macro F1 считается по трём классам
AM, FM и Noise, с центральными и смещёнными FM в одном классе.
Группы станций и остальных записей разделены между обучением,
валидацией и тестом. Реальные смещённые трассы участвовали только в тесте.
Станция, отсутствующая в основной выборке, проверялась моделью,
обученной на всех основных группах.

- MLP получает средний спектр на 501 точку. Скрытые слои содержат
  200 и 20 нейронов с ReLU и dropout 0,1 после второго слоя.
- 1D CNN получает тот же средний спектр. Deep Sets применяет тот же
  свёрточный блок к каждой развёртке и усредняет признаки.
- Для каждой основной записи FM заранее создаются 16 синтетических
  вариантов. Для каждого span (250 и 400 кГц) четыре раза выбирается
  по одному равномерному случайному сдвигу влево и вправо. Модули
  сдвигов ограничены 80 и 180 кГц соответственно. Одинаковый сдвиг
  применяется ко всем развёрткам выбранного варианта записи.
- На каждой эпохе запись FM с вероятностью 50% заменяется одним из
  её 16 вариантов. Число обучающих шагов на эпоху сохраняется.
  AM и Noise используются как записаны. Валидация проходит на реальных
  окнах и используется для выбора числа эпох.

Для CNN и Deep Sets базовые результаты взяты из [предыдущего прогона](modulation_deep_sets.md).
Для MLP на среднем спектре базовый вариант обучен в этом эксперименте.
GB взят из [прогона со случайными сдвигами](gb_shift_augmentation.md).
У GB сдвиг выбирался на окно, а у нейросетей — на запись и эпоху.
Поэтому таблица сравнивает готовые варианты обучения на общем тесте.

## Результаты нейросетей

| Модель | Сдвиги FM | Macro F1 | F1 класса FM | Смещённые FM → FM | AM/FM → Noise | Noise → AM/FM | p50 / p95, мс |
|---|---|---:|---:|---:|---:|---:|---:|
| MLP на среднем | Нет | 0,773 | 0,661 | 3 / 615 | 641 | 5 | 0,166 / 0,238 |
| MLP на среднем | Да | 0,841 | 0,801 | 275 / 615 | 368 | 94 | 0,179 / 0,264 |
| 1D CNN на среднем | Нет | 0,804 | 0,694 | 23 / 615 | 385 | 0 | 0,268 / 0,304 |
| 1D CNN на среднем | Да | 0,913 | 0,891 | 446 / 615 | 210 | 0 | 0,293 / 0,518 |
| Deep Sets | Нет | 0,835 | 0,756 | 193 / 615 | 276 | 5 | 0,873 / 0,944 |
| Deep Sets | Да | 0,928 | 0,909 | 453 / 615 | 163 | 0 | 0,893 / 1,222 |

GB со случайными сдвигами FM в предыдущем прогоне дал 0,936 Macro F1,
распознал 516 из 615 смещённых окон, пропустил 108 сигналов и
дал 73 ложных срабатывания. У 1D CNN и Deep Sets после аугментации
все 205 смещённых окон при span 400 кГц классифицированы как FM.
При 250 кГц те же сети правильно распознали 241 и 248 окон из 410.
Время относится к обработке уже полученных семи развёрток на одном потоке CPU.

## GB с уточнением центра по принятому спектру

В дополнительном прогоне обучающие данные GB и его параметры
совпали с базовым вариантом без аугментации. На тесте признаки
считались относительно взвешенной медианы частоты во всём принятом
спектре. В качестве веса каждой точки использовалась линейная
мощность сверх медианной мощности спектра с отсечением отрицательных
значений. Истинная частота станции в расчёт центра не передавалась.
Центр уточнялся для всех тестовых окон, включая AM и Noise.

Получено **0,958 Macro F1** и **96,06% accuracy**. Из 615 смещённых
FM правильно распознаны 610 (405 из 410 при span 250 кГц и 205 из 205
при 400 кГц). Остальные пять классифицированы как AM.
Из 3 690 окон с сигналом 20 приняты за шум. Среди 902 шумовых окон
было 74 ложных срабатывания. Прогон проверяет один кандидат на окно,
с исходными диапазонами и отдельно от работы обзорного детектора.

## Воспроизведение

```powershell
foreach ($model in @('mlp_mean_spectrum', 'cnn_mean_spectrum', 'deep_sets')) {
    python scripts/evaluate_neural_shift_augmentation.py --project . --model $model --output ".local/neural_shift/$model"
}
python scripts/evaluate_gb_recentering.py --project . --output .local/gb_recentering
```

Опция `--with-baseline` также повторно обучает базовую CNN или Deep Sets.
Окружение то же, что для [базовой 1D CNN](modulation_cnn1d_baseline.md).
