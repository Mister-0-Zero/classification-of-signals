## Как проверяли

- Использовали 97 записей из 28 групп. В каждой записи 50 развёрток по 501 точке при span 250 кГц. Все развёртки одного окна относятся к одной записи. Внешние девять фолдов совпадают с предыдущей оценкой классификатора. Группы AM, FM и Noise разделены тем же способом.
- Для всех длин использовали одни и те же конечные развёртки с нулевыми индексами 9–49. Всего 3 977 прогнозов на вариант: 1 968 AM, 1 107 FM и 902 Noise.
- Уровни по одинаковым частотным отсчётам усредняли в линейной мощности, затем преобразовывали результат обратно в dBm. После этого считали те же 10 признаков, что и для итогового классификатора. GB переобучали для каждой длины с фиксированными параметрами итоговой модели.
- Проверка на неперекрывающихся окнах использует только концы 9, 19, 29, 39 и 49. При 485 прогнозах на вариант Macro F1 для 1, 2, 3, 5, 7 и 10 спектров составил соответственно 0,874, 0,923, 0,941, 0,940, 0,976 и 0,973. Это дополнительная проверка на тех же записях, а качество на новых измерениях остаётся открытым.

Для времени выполнено 582 измерения на вариант после прогрева. Замер включал
усреднение, расчёт признаков и прогноз одного спектра на локальном ПК. Время
работы прибора и передачи трасс в замер не входит. По журналам старого сбора
медианная длительность записи в пересчёте на одну развёртку около 0,22 с.
При таком темпе окно из трёх развёрток получает первую оценку примерно через
0,44 с после первой трассы, окно из семи через 1,33 с. На реальном сканере
этот интервал надо измерить отдельно, особенно при переходах между частотами.

## Воспроизведение

Из корня репозитория с локальными измерениями в `data/` и зависимостями
[итоговой модели](../../models/modulation/README.md):

```powershell
python scripts/evaluate_gb_averaging.py --project . --output .local/gb_sweep_averaging
```

Скрипт сохраняет общие показатели, прогнозы и проверку на неперекрывающихся
окнах. Эксперимент не меняет утверждённую модель или настройки приложения.

## Обучение на одном спектре, тест на усреднённых

В этом эксперименте на каждом из девяти фолдов обучался один GB на одиночных
спектрах. Одна и та же модель предсказывала классы на всех шести длинах окна
из отложенных групп. Ни записи, ни группы теста не попадали в обучение.
Использованы те же 3 977 моментов. Для окна из одного спектра совпали все
прогнозы первого и второго экспериментов.

| 3 | 93,99% | 0,940 | 0,947 | 0,905 | 0,968 | 60 | 0 | 1,00 | 0,940 |
| 5 | 95,22% | 0,952 | 0,958 | 0,927 | 0,972 | 52 | 0 | 1,01 | 0,946 |

Без переобучения Macro F1 заметно вырос даже при двух спектрах. При 7 и 10
спектрах польза от обучения на таком же усреднении видна прежде всего по
пропускам: 50 против 36 для окна 7, 49 против 34 для окна 10. При обучении на
одиночных спектрах на 902 шумовых окнах с длиной от 3 не было ложных сигналов.
В этом тесте использованы заранее размеченные шумовые записи. Проверка на
ложных срабатываниях реального детектора остаётся отдельной задачей.

На подвыборке из 485 неперекрывающихся окон Macro F1 для 1, 2, 3, 5, 7 и
10 спектров составил 0,874, 0,933, 0,932, 0,951, 0,959 и 0,954 соответственно.
Замеры вычислений относятся к этому отдельному прогону. Интервал между съёмами
спектров в них не входит.

```powershell
python scripts/evaluate_gb_averaging.py --project . --output .local/gb_averaging_transfer --train-single
```

## Общая оценка со смещёнными FM

В тесте по семи спектрам использованы те же 4 592 окна, что у
[Deep Sets и 1D CNN](modulation_deep_sets.md). В Macro F1 входят AM,
Noise и FM, объединяющий 1 107 центральных и 615 смещённых окон.
Частота кандидата для GB равна записанному центру окна анализатора.
Смещённые FM использованы только для теста. Для известных станций
использован фолд, исключающий станцию из обучения. Для станции,
отсутствующей в основных записях, использована модель, обученная на
всех основных записях. Прогнозы GB на 3 977 основных окнах точно
совпали с прежними прогонами в обоих режимах обучения.

| Модель, окно из 7 спектров | Macro F1 | F1 AM | F1 FM | F1 Noise | Центральный FM → FM | Смещённый FM → FM | Смещённый FM → Noise | AM/FM → Noise |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| GB, обучение на одиночных | 0,874 | 0,963 | 0,841 | 0,817 | 1 061 / 1 107 | 260 / 615 | 354 / 615 | 404 / 3 690 |
| GB, обучение на средних | 0,889 | 0,960 | 0,862 | 0,846 | 1 060 / 1 107 | 266 / 615 | 287 / 615 | 323 / 3 690 |
| 1D CNN на среднем спектре | 0,804 | 0,894 | 0,694 | 0,824 | 894 / 1 107 | 23 / 615 | 350 / 615 | 385 / 3 690 |
| Deep Sets | 0,835 | 0,885 | 0,756 | 0,865 | 920 / 1 107 | 193 / 615 | 258 / 615 | 276 / 3 690 |

На 5 600 одиночных спектрах (4 850 основных и 750 смещённых) GB
получил Macro F1 0,815, распознал 379 из 750 смещённых FM и принял
328 из них за шум. В этом прогоне использовались параметры утверждённого GB,
фиксированные для всех фолдов. На основных спектрах эта конфигурация дала
0,868 Macro F1. Прежняя оценка 0,864 получена при подборе параметров заново
в каждом внешнем фолде.

Для воспроизведения нужен PyTorch из окружения MLP для общего загрузчика
смещённых трасс.

```powershell
python scripts/evaluate_gb_shifted.py --project . --output .local/gb_shifted
```
