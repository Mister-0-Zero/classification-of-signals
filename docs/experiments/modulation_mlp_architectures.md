# Размер MLP для классификации спектров

Одно увеличение сети не устранило ошибки на смещённых спектрах. Среди
четырёх проверенных вариантов лучший результат на них дала MLP
`501 → 32 → 32 → 3`: полнота FM выросла с 60,9% до 65,6%. На
центрированных спектрах эта архитектура уступила базовой по Macro F1.

| Архитектура | Параметры | Accuracy | Macro F1 | F1 AM | F1 FM | F1 Noise | Сигнал → шум | Шум → сигнал | Время p50 / p95, мс |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 501 → 32 → 16 → 3 | 16 643 | 90,08% | 0,896 | 0,925 | 0,839 | 0,924 | 128 | 46 | 0,046 / 0,084 |
| 501 → 16 → 16 → 3 | 8 355 | 90,33% | 0,898 | 0,926 | 0,850 | 0,918 | 144 | 44 | 0,045 / 0,082 |
| 501 → 32 → 32 → 3 | 17 219 | 89,63% | 0,892 | 0,918 | 0,844 | 0,914 | 132 | 64 | 0,046 / 0,085 |
| 501 → 32 → 32 → 16 → 3 | 17 699 | 90,31% | 0,897 | 0,929 | 0,844 | 0,918 | 138 | 50 | 0,055 / 0,093 |

| Архитектура | FM при span 250 кГц | FM при span 400 кГц | FM на всех смещённых | Смещённые FM → шум |
|---|---:|---:|---:|---:|
| 501 → 32 → 16 → 3 | 234 / 500 | 223 / 250 | 457 / 750 | 273 |
| 501 → 16 → 16 → 3 | 223 / 500 | 215 / 250 | 438 / 750 | 295 |
| 501 → 32 → 32 → 3 | 273 / 500 | 219 / 250 | 492 / 750 | 234 |
| 501 → 32 → 32 → 16 → 3 | 251 / 500 | 214 / 250 | 465 / 750 | 263 |

У варианта 32 → 32 весь выигрыш пришёлся на окно 250 кГц. В нём было
39 дополнительных правильных прогнозов FM, а на 400 кГц — на 4 меньше.
Уменьшение размера сети почти вдвое сохранило Macro F1 на основной
выборке, однако пропусков реальных сигналов стало больше.

Сохранены вход 501 точка, ReLU, отсутствие dropout и прежний протокол
обучения. Архитектуры обучены на одних и тех же центрированных группах.
Число эпох подбиралось на внутренних группах. Тестовые FM-станции не
попадали в обучение модели, которой их проверяли. Смещённые трассы не
центрировались и не использовались для подбора. Базовый вариант
воспроизвёл все 4 850 центрированных и 750 смещённых прогнозов прежней
проверки.

Время включает подготовку входа и один прогноз на CPU Ryzen 5 7500F,
582 измерения на вариант. Время работы анализатора сюда не входит.
