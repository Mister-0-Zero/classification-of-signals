# Аугментация частотным сдвигом для Gradient Boosting

Взяли GB на десяти признаках, обученный на средних из семи спектров.
Сравнили базовое обучение, добавление сдвинутых FM и добавление сдвинутых
окон всех трёх классов. Последний вариант проверяет, помогает ли применять
одинаковое преобразование к AM, FM и шуму.

## Фиксированные сдвиги

Для каждого выбранного обучающего окна оставляли оригинал и строили
четыре копии среднего спектра. При span 250 кГц сдвигали на ±80 кГц,
при span 400 кГц — на ±180 кГц. Геометрию выбрали по известным настройкам
отдельного сбора смещённых FM. Частотные отсчёты интерполировали в
линейной мощности, вышедшую за границы часть обрезали. Для отсутствующих
частот использовали продолжение крайнего участка шириной около 12,5 кГц
того же обучающего спектра с ограничением пиков. Это приближение фона
и края полосы.

Синтетические копии наследовали группу, запись и фолд оригинала.
У всех вариантов те же параметры GB и нормирование весов по группам
и классам. Тестовые окна использовались как измерены. Итоговый Macro F1
считается по 4 592 окнам, включая 615 реальных смещённых FM.
Полнота на смещении считается по 615 окнам из 15 записей.
В этой части теста истинные метки принадлежат одному классу, поэтому
результат представлен числом распознанных FM и пропусков в шум.

### Результаты фиксированных сдвигов

| Аугментация | Общий Macro F1 | F1 класса FM | Macro F1 без смещённых | Смещённые FM → FM | Смещённые FM → Noise | Все AM/FM → Noise | Noise → AM/FM |
|---|---:|---:|---:|---:|---:|---:|---:|
| Без сдвигов | 0,889 | 0,862 | 0,973 | 266 / 615 (43,3%) | 287 | 323 | 4 |
| Сдвиги только FM | 0,920 | 0,913 | 0,933 | 529 / 615 (86,0%) | 85 | 93 | 139 |
| Сдвиги AM, FM и шума | 0,926 | 0,913 | 0,957 | 464 / 615 (75,4%) | 115 | 129 | 54 |

| Аугментация | Смещённые FM при 250 кГц | Смещённые FM при 400 кГц | Записей с большинством ответов FM |
|---|---:|---:|---:|
| Без сдвигов | 225 / 410 | 41 / 205 | 6 / 15 |
| Сдвиги только FM | 405 / 410 | 124 / 205 | 13 / 15 |
| Сдвиги AM, FM и шума | 390 / 410 | 74 / 205 | 11 / 15 |

Сдвиги всех классов дали максимальный общий Macro F1 и меньше
ложных срабатываний на шуме, чем сдвиги только FM. Сдвиги только FM
дали максимальную полноту на смещении и минимальное число пропусков
сигнала. Числа относятся к перекрывающимся окнам одной серии измерений.
Следующая проверка на независимом сборе должна включать несколько span,
разные смещения одних и тех же станций и реальные смещённые AM.

## Случайные сдвиги

Для каждого окна отдельно выбираем четыре независимых смещения
из равномерных распределений. При span 250 кГц выбираем одно
смещение из диапазона от −80 до 0 кГц и одно от 0 до +80 кГц.
При span 400 кГц используем диапазоны от −180 до 0 кГц и от 0
до +180 кГц. Исходные окна, число копий и способ формирования
спектра совпадают с экспериментом выше. Для двух вариантов
обучения используются одни и те же случайные смещения FM.
Начальное значение генератора фиксировано для воспроизведения.

### Результаты случайных сдвигов

| Аугментация | Общий Macro F1 | F1 класса FM | Macro F1 без смещённых | Смещённые FM → FM | Смещённые FM → Noise | Все AM/FM → Noise | Noise → AM/FM |
|---|---:|---:|---:|---:|---:|---:|---:|
| Случайные сдвиги только FM | 0,936 | 0,927 | 0,956 | 516 / 615 (83,9%) | 99 | 108 | 73 |
| Случайные сдвиги AM, FM и шума | 0,928 | 0,913 | 0,971 | 425 / 615 (69,1%) | 135 | 147 | 24 |

При сдвигах только FM случайный вариант дал 403 из 410 правильных
ответов при span 250 кГц и 113 из 205 при span 400 кГц. По сравнению
с фиксированными сдвигами Macro F1 вырос на 1,63 процентного пункта
и стало на 66 меньше ложных сигналов на шуме. При этом число правильных
ответов на смещённых FM уменьшилось на 13. В тесте смещённых FM есть
только реальные записи с модулями сдвига 80 и 180 кГц. Качество
на промежуточных смещениях нужно проверить на отдельных реальных записях.

## Воспроизведение

В том же окружении, что и для [проверки GB на смещении](gb_sweep_averaging.md):

```powershell
python scripts/evaluate_gb_shift_augmentation.py --project . --output .local/gb_shift_augmentation
```

Этот запуск использует случайные сдвиги с `--seed 20261123`.
Фиксированные сдвиги воспроизводятся тем же скриптом из коммита
`e698b3c`.
