# Правила проекта ВКР

## Публикация изменений

Алексей поручил автоматически публиковать на GitHub завершённые изменения
в этом проекте. После работы, которая меняет файлы проекта, проверь изменения,
запусти уместные проверки, создай коммит и отправь его в
`Mister-0-Zero/classification-of-signals` через `origin` без отдельного
подтверждения. Это правило действует, если Алексей явно не попросил отложить
публикацию или оставить результат только локально.

- Добавляй в коммит файлы завершённой задачи. Проверяй состояние Git, чтобы
  не включить параллельные правки, которые не относятся к задаче.
- Используй `main` для обычных совместимых изменений в этом проекте, если
  текущая задача не предусматривает отдельную ветку или PR. Сверяй состояние
  удалённой ветки перед отправкой и сохраняй изменения с других ПК. Не применяй
  принудительную отправку. Если возник конфликт, который нельзя безопасно
  решить, сообщи о нём и сохрани локальную работу.
- Исходные измерения, исключённые выборки, экспериментальные архивы, сборки
  и локальные окружения хранятся отдельно. Утверждённые артефакты моделей
  и необходимая документация хранятся в `models/`.
- После отправки проверь удалённый коммит и дай ссылку в итоговом сообщении.
