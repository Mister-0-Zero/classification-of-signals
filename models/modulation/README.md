# Сохранённый Gradient Boosting для AM/FM/Noise

Для проекта ВКР зафиксирован Gradient Boosting на 10 признаках с подбором в пользу меньшего числа реальных сигналов, ошибочно отнесённых к шуму. Артефакт обучен на всех 97 основных записях. Его параметры и контрольная сумма находятся в `manifest.json`.

Классификатор получает один спектр после обзорного обнаружения и уточняющего измерения. Он возвращает одну метку из `AM`, `FM` и `Noise`. Код сканера SignalScope находится в [desktop/](../../desktop/README.md). SignalScope использует отдельные веса `scanner_gb1.joblib`, `scanner_gb7.joblib`, `scanner_mlp.npz` и `scanner_sets.npz`. Они подготовлены по 97 основным сериям скриптом `scripts/export_scanner_models.py`. Для Deep Sets длительность обучения выпуска выбрана на внутреннем групповом разбиении (13 эпох). Числа в итоговом отчёте относятся к проверке схем на отложенных группах.

Выбранные режимы с этим семейством моделей и нейросетями описаны
в [итоговом отчёте ВКР](../../docs/modulation_pipeline.md).

## Запуск из корня репозитория

Окружение проверено с Python 3.11.9 и версиями библиотек из `requirements.txt`.

```powershell
python -m pip install -r models/modulation/requirements.txt
```

```python
from models.modulation.classifier import ModulationClassifier

classifier = ModulationClassifier()  # Один раз за запуск.
label = classifier.predict(frequency_hz, amplitude_dbm, candidate_hz)
```

`frequency_hz` и `amplitude_dbm` — два одномерных массива одного спектра. Частоты строго возрастают. `candidate_hz` — центр кандидата в герцах; для его вычисления сканер использует результат обнаружения. Трасса с недостаточным покрытием частотных зон вызывает `ValueError`. Эту ошибку интеграция должна обработать отдельно от вердикта `Noise`.

Признаки считаются на сетке 1 кГц в доступной части окна ±125 кГц. Используются ширины 50% и 90% мощности и их отношение, доля мощности в центре, зеркальная асимметрия и контрасты в пяти частотных зонах. Фон не вычитается. Модель использует исходный выбор класса с максимальной оценкой GB.

## Что подтверждено измерениями

В групповой проверке процедуры подбора получено **0,864 Macro F1**. Из 3 750 отложенных AM/FM спектров 100 были предсказаны как шум. Из 1 100 шумовых спектров 40 были предсказаны как AM/FM. Это прогнозы девяти внешних фолдов, где параметры подбирались отдельно. Сохранённая модель обучена затем на всех записях и собственной независимой тестовой оценки пока не имеет.

Основные замеры сделаны на **501 точку при span 250 кГц**. Это рекомендуемые параметры для первого теста на приборе. Работа с оценённым сканером центром, иными span и приборами требует отдельной проверки. Старые проверки показали, что уменьшение span до 180 кГц может резко ухудшать отбраковку шума. Используй при загрузке файл `gradient_boosting.joblib` из этого каталога.
